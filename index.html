Logical Formula

S ↔ (U ∨ L ∨ M ∨ P)
∨ OR — true when at least one operand is true
↔ Biconditional — true when both sides match
// Programming equivalent
const isSpam = U || L || M || P;

    Inference Rule Used

    Applying Modus Ponens

    Modus Ponens — Structure

    Premise 1 (U ∨ L ∨ M ∨ P) → S
    Premise 2 (U ∨ L ∨ M ∨ P)
    Conclusion S

    Example — SPAM Case

    U = FALSE, L = FALSE, M = TRUE, P = FALSE

    FALSE ∨ FALSE ∨ TRUE ∨ FALSE = TRUE

    Therefore S = TRUE

    The email is classified as SPAM.

    Example — NOT SPAM Case

    U = FALSE, L = FALSE, M = FALSE, P = FALSE

    FALSE ∨ FALSE ∨ FALSE ∨ FALSE = FALSE

    Therefore S = FALSE

    The email is classified as NOT SPAM.
